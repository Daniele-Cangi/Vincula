Linux Dock per Windows

Sul desktop Windows, apri Linux Dock. Il collegamento avvia
l'app installata nel profilo Windows, sotto %LOCALAPPDATA%\Linux Dock.

Stato mostra sistema, tempo di attività, CPU, RAM e dischi del PC Linux.
Trasferimenti copia un file alla volta in entrambi i sensi. Usa un percorso
Linux assoluto come /home/utente/documento.txt. La cartella di destinazione
deve esistere. Per un file esistente, scegli un nome diverso. L'invio verso
Linux richiede un filesystem che supporti la rinomina atomica senza sostituzione.
Bash esegue un file .sh con l'account SSH Linux e mostra output, errori e codice di
uscita. Lo script parte da una directory temporanea sul PC Linux e funziona
senza input interattivo. Usa percorsi assoluti per i file di cui ha bisogno.
Linux arresta lo script e i suoi processi dopo 10 minuti. L'app indica quando
accorcia un output lungo o perde la conferma dell'esito.

Desktop remoto
Premi «Desktop remoto» per vedere la sessione già aperta su Ubuntu
e usare mouse e tastiera. Il PC da controllare deve avere la sessione grafica X11 aperta.
Chiudi il visualizzatore o premi «Chiudi desktop remoto» per chiudere il tunnel.
Il traffico VNC passa nel tunnel SSH sulla rete Ethernet. La porta VNC 5909
ascolta solo in loopback su entrambi i PC. Gli appunti restano locali.


Condividere il mouse e la tastiera di Windows
Linux Dock avvia la condivisione all'apertura e ritenta se il collegamento
cade. Ubuntu deve avere una sessione grafica aperta. Il lato iniziale è
«A sinistra di Windows». Nella scheda «Mouse e tastiera» puoi cambiarlo
anche durante la condivisione. Al cambio di lato la sessione si riconnette
automaticamente e l'app ricorda la scelta.
Porta il puntatore oltre il bordo scelto per continuare sull'altro PC.
Ctrl+F12 cambia computer. «Disattiva condivisione», accanto a «Desktop remoto»,
ferma la sessione da qualsiasi scheda, anche durante un trasferimento o uno
script. I tentativi automatici riprendono alla prossima apertura o dopo
«Attiva condivisione».
Se l'arresto dei processi non è verificabile, l'app mostra «Arresto non confermato».
Gli appunti sono condivisi in entrambe le direzioni per impostazione
predefinita. Copia il testo, passa all'altro schermo e incolla normalmente.
Per disattivare gli appunti, ferma la sessione e deseleziona la relativa
casella prima di riconnetterti. Per copiare un file usa «Trasferimenti».
Barrier 2.4 può svuotare gli appunti locali di Ubuntu all'avvio della
sessione anche quando la casella è deselezionata.

La modalità usa Deskflow su Windows. Su Ubuntu il ricevitore usa Barrier
in X11 o Deskflow in Wayland. Al primo avvio su Wayland autorizza il
controllo e gli appunti nella finestra di GNOME. Per gli appunti su
Wayland, il ricevitore usa Deskflow compilato con libportal 0.10 o
successivo. Il segnale di connessione usato dall'app Windows è esposto
con il livello di diagnostica DEBUG del ricevitore.
La connessione passa nel tunnel SSH e usa TLS autenticato da entrambe
le parti. Le porte interne ascoltano su loopback.

Su Ubuntu installa start-deskflow-wayland.sh come eseguibile
~/.local/share/linux-dock/vnc/deskflow-wayland/start-client. Il profilo
settings/dock-client.conf usa computerName=dock-ubuntu e port=24801 in
[core], remoteHost=127.0.0.1 in [client], tlsEnabled=true,
checkPeerFingerprints=true e il percorso del certificato esistente in
[security], level=DEBUG in [log]. Il file settings/tls/trusted-servers
contiene l'impronta SHA-256 di Windows già verificata, nel formato
v2:sha256: seguito dai 64 caratteri esadecimali senza separatori.

Icone
Generate con ImageGen. Il prompt comune descrive uno scudo compatto
in grafite con bordo metallico e connettori Ethernet su sfondo trasparente.
Windows Dock usa quattro riquadri ciano. Linux Dock usa un simbolo da
terminale viola e verde acido.

L'alias SSH linux-dock, configurato in %LOCALAPPDATA%\Linux Dock\ssh_config,
seleziona indirizzo e account Linux. Nella configurazione di esempio Windows
usa 192.168.77.2 e Linux risponde su 192.168.77.1:2222.
Il servizio Linux può chiamarsi linux-dock-sshd.service e girare nella sessione
dell'utente Linux. Puoi verificarlo con systemctl --user status linux-dock-sshd.
Per la connessione automatica, abilita l'avvio automatico del profilo
Ethernet dedicato alla porta configurata.

LinuxDock.cs contiene il sorgente dell'app installata.
